Interactive Dashboard Calculator to Enhance Operational Efficiency at Mechapres

This project was aimed at designing an interactive dashboard calculator that will foster operational efficiency at Mechapres, which is a small to medium-sized precision engineering company working in a resource limited manufacturing environment.

Tools: Python, Pandas, Plotly, Streamlit

  • Check it out

Project Overview

The primary objective of this project is to design and implement an interactive dashboard calculator to improve operational performance at Mechapres. Specifically, the project aims to develop a tailored dashboard that supports production and cost management, automate key operational calculations, and present insights through intuitive and easily interpretable visualizations. In addition, the project seeks to assess the effectiveness of the dashboard in improving decision accuracy, reducing computational time, and supporting efficient resource utilization.

Project Resources

  • View the live dashboard
  • View the source code on GitHub

Approach Used

The project used the CRISP-DM business analytics methodology to develop and evaluate an interactive dashboard calculator for Mechapres.

The project followed five main stages:

  1. Business understanding
    The project identified Mechapres’ operational problems, particularly manual cost calculations, fragmented data, inconsistent reporting, and delays in decision-making.
  2. Data understanding and preparation
    Historical production, financial, material, labour, and machine-use data were collected and examined. The data was cleaned, missing values and inconsistencies were addressed, and new measures such as unit production cost and resource-utilisation rates were created.
  3. Modelling and dashboard development
    Formula-based and rule-based calculations were developed for production costs, material consumption, labour allocation, machine utilisation, savings, payback period, and other performance indicators. These calculations were incorporated into an interactive dashboard with filters, input fields, tables, and visualisations.
  4. Evaluation
    The dashboard was tested for computational accuracy, reliability, responsiveness, and usability. Its outputs were compared with historical data, while user testing and feedback were used to assess whether it met the needs of production and finance staff.
  5. Deployment
    The final dashboard was implemented using Streamlit, a Python-based web application framework. Users were introduced to the system, and its effectiveness was assessed based on reduced manual calculation time, improved reporting consistency, and better access to operational information.

Key Findings

  • Improved cost estimation: The dashboard automatically calculated total production cost, unit cost, material costs, labour costs, and other operational expenses more consistently.
  • Reduced manual effort and errors: Automating calculations reduced dependence on spreadsheets and manual processes, helping to minimise calculation errors and delays.
  • Better resource monitoring: The tool provided clearer information about material consumption, labour allocation, and machine utilisation, making it easier to identify inefficient resource use.
  • Faster decision-making: Managers could change inputs and immediately view updated results, allowing them to assess different production volumes, material costs, labour requirements, and operational scenarios.
  • Improved data visibility: Previously fragmented operational and financial information was consolidated into one interactive dashboard, creating a more accessible source of information for decision-makers.
  • Scenario and investment analysis: The dashboard supported low-case and high-case analysis and generated indicators such as estimated savings, investment requirements, payback period, internal rate of return, net present value, and potential carbon-emission reductions.
  • Improved reporting consistency: Standardised calculations and visual outputs made reports easier to understand and compare across production periods or operating conditions.
  • Positive user response: Testing with production and finance users indicated that the dashboard was considered relevant, understandable, and useful for operational planning and management decisions.
  • Practical suitability for SMEs: The use of Streamlit demonstrated that a relatively simple, Python-based dashboard could provide useful decision-support capabilities without requiring a large enterprise system or full ERP integration.

Project Outcome

The project outcome was the successful development of an interactive dashboard calculator for Mechapres using Streamlit and the CRISP-DM methodology.

The dashboard brought together production, material, labour, machine, and financial information in one system. It automated important calculations, including:

  • Total production cost and cost per unit.
  • Material consumption and utilisation.
  • Labour allocation and productivity.
  • Machine utilisation.
  • Estimated savings and investment requirements.
  • Payback period, internal rate of return, and net present value.
  • Potential carbon-emission reductions.

The project also showed that the dashboard could provide faster, more consistent, and more transparent operational information than manual calculations. Users could adjust inputs and immediately view updated results, making it easier to compare scenarios and support production and investment decisions.

Predictive Crime Analytics Dashboard, Visualising Crime Patterns and Forecasting Trends in Northern Ireland

This report explores the application of predictive analytics in the context of crime data analysis, specifically focusing on a dataset from Northern Ireland that includes various crime types and locations. The primary goal of this analysis is to build a predictive analytics dashboard that can assist stakeholders in understanding crime patterns and making informed decisions about resource allocation, law enforcement strategies, and public safety initiatives.

Tool: Python, Streamlit, Pandas, ARIMA

  • Check it out

Project Overview

Developed an interactive predictive analytics dashboard to analyse reported crime patterns in Northern Ireland and forecast future crime trends. The project used historical data from Data.police.uk covering May 2022 to April 2025. It was designed to support data-driven resource allocation, public-safety planning, and proactive decision-making.

Project Resources

  • View the live dashboard
  • View the source code on GitHub

Business Problem

Law-enforcement and public-safety stakeholders need to understand where and when crime occurs so that resources can be allocated more effectively. This project addressed the challenge by combining historical crime analysis, location-based visualisation, seasonal trend analysis, and six-month forecasting.

Objectives

  • Identify the most frequently reported crime categories.
  • Detect geographical crime hotspots.
  • Analyse seasonal and monthly crime patterns.
  • Forecast crime trends for the following six months.
  • Present the findings through an interactive dashboard.
  • Demonstrate how predictive analytics can support public-safety planning.

Methodology

Applied the CRISP-DM framework across the project:

  1. Business understanding.
  2. Data understanding.
  3. Data preparation.
  4. Exploratory data analysis.
  5. Predictive modelling.
  6. Model evaluation and deployment.

The dataset was cleaned by removing duplicates, eliminating irrelevant fields, addressing incomplete records, filtering vague location entries, and converting date fields into a suitable format for time-series analysis.

Key Insights

  • Anti-social behaviour was the most frequently reported crime category.
  • Belfast and other urban areas appeared as key crime hotspots.
  • Crime levels varied across seasons and months.
  • The ARIMA model forecast moderate fluctuations in future crime levels.
  • Violent crime and burglary were forecast to increase during colder months.
  • The dashboard enabled users to examine crime types, locations, seasonal patterns, and future forecasts interactively.
